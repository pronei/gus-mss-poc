# S4 ground-truth candidates - Spinnaker release history

Scope: every Spinnaker release whose changelog page is dated within the last five
years (2021-09-11 .. 2026-09-11), oldest to newest; see `releases.tsv`. Sources are
the per-version changelog pages on spinnaker.io, the spinnaker/spinnaker issue and
pull-request tracker (which since 2025.0.0 is also the monorepo for all ten
services), and the spinnaker/spinnaker.io documentation repository.

Every row carries a sentence quoted verbatim and the URL it was read from. Nothing
here is inferred from a code diff. A release pair that does not appear below is
"no evidence found", not "safe" (plan D10).

Transcription rule: quotes from spinnaker.io changelog pages are taken from that
page's markdown source in `spinnaker/spinnaker.io`, so backtick code spans and
straight apostrophes are preserved; Hugo renders those as `<code>` spans and
typographic apostrophes, and joins the hard line wraps of the 2026.3.0 page, but the
wording is unchanged. Quotes from GitHub issues and pull requests are as posted.

`kind` is one of `breaking`, `compat-note`, `upgrade-order`, `deprecation-removed`.
`services` names the caller and the provider where the source identifies them.
Where a source states versions itself (an issue reporting an upgrade), `pair` uses
those versions verbatim rather than the nearest consecutive pair.
